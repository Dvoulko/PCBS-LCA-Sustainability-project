# PCB LCA Sustainability Project
### Life Cycle Assessment (LCA) for PCBs using OpenLCA

---

## 🇬🇧 English Version

### Description
This project presents a comprehensive Life Cycle Assessment (LCA) for Printed Circuit Boards (PCBs). Utilizing **OpenLCA** software, the study evaluates and compares the environmental impacts of manufacturing processes using primary raw materials versus integrating secondary (recycled) sources. The goal is to highlight potential carbon footprint reductions and promote sustainable electronic manufacturing practices.

### Software & Tools
*   **LCA Software:** OpenLCA
*   **Data Databases:** Ecoinvent / openLCA databases
