# pcb-lca-sustainability-project
Life Cycle Assessment (LCA) for PCBs using OpenLCA.
# Αξιολόγηση Κύκλου Ζωής (LCA) για PCBs

Αυτό το project περιλαμβάνει την πλήρη μελέτη αξιολόγησης του κύκλου ζωής για PCBs (Printed Circuit Boards), συγκρίνοντας τη χρήση πρωτογενών υλικών με δευτερογενείς πηγές στο λογισμικό OpenLCA.
